# CV online · Felipe Contreras

Sitio estático (HTML + CSS + JS, sin dependencias) para GitHub Pages.

- `index.html` – contenido (español; traducción al inglés vía atributos `data-en`)
- `assets/style.css`, `assets/app.js` – estilos e interactividad (tema claro/oscuro, ES/EN, animaciones)
- `assets/Felipe_Contreras_CV.pdf` – CV descargable
- `assets/foto.jpg` – foto

Para probar localmente: `python3 -m http.server` y abrir http://localhost:8000
